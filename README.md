# Wykresiki

Aby uruchomić projekt należy wykonać polecenie
```
docker compose up --build
```

Aby zatrzymać należy wykonać
```
docker compose down
```

Do tego konieczne jest zmodyfikowanie pliku 
`mailer.php` i `secret.php` w celu ustawienia
odpowiedniej skrzynki pocztowej oraz jej 
poświadczeń

Napisano przez OB w 2026
